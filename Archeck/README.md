# Archeck

Инструмент контроля целостности файлов и их архивации через 7-Zip.
Написан на PowerShell, запускается батником.

## Возможности

- Создание базы SHA-256 хешей (`FileHashes.csv`)
- Проверка файлов по базе (вывод на экран или отчёт `ErrorLog.txt`)
- Архивация в `.zip` / `.7z` (с опциональным паролем и разбиением на тома)
- Распаковка с двухэтапной проверкой: целостность томов → сверка с оригиналами
- Автоматическое сохранение архивов в уникальные папки `_archive_backup_<дата>`

## Требования

- Windows 10/11
- PowerShell 5.1 (встроенный) или новее
- [7-Zip](https://www.7-zip.org/), установленный в `C:\Program Files\7-Zip\`

## Запуск

Дважды щёлкните по `Start.bat` или выполните в терминале:

```bat
Start.bat
```

Либо напрямую:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\HashTool.ps1
```

## Использование

1. Укажите путь к папке (Enter — текущая папка).
2. Выберите режим сканирования: только корень или всё с подпапками.
3. Выберите действие из меню:
   - `1` — создать базу хешей
   - `2` — проверить файлы (экран)
   - `3` — проверить и сохранить отчёт об ошибках
   - `4` — упаковать в архив
   - `5` — распаковать с проверкой
   - `6` — выход

## Примечания

- Служебные файлы (`FileHashes.csv`, `OriginalHashes.csv`, `ErrorLog.txt`, папки `_archive_backup_*`) исключены из git через `.gitignore`.
- Пароль архива передаётся 7-Zip через аргументы командной строки и может быть виден в списке процессов во время работы.
